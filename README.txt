If your photos are PNG, either convert them to JPG or change the `.jpg` extension in `index.html` and `script.js`.

## How to change Bryson Story
Open `index.html`, find:
<!-- ANDIKA STORY YAKO HAPA -->

Replace the paragraph below it with your own story.

## Preview in VS Code
Open the folder in VS Code and use Live Server, or double-click `index.html`.

## GitHub Pages
Upload/push the project to a GitHub repository, then enable GitHub Pages from the repository's Settings > Pages.
